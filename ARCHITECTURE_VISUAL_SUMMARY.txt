🔄 CRITICAL WORKFLOWS

WORKFLOW #1: LEAVE REQUEST (Multi-Level Approval)
──────────────────────────────────────────────────
Employee Submits Leave Request
         ↓
System Validates (Balance, Conflicts, Policy)
         ↓
Initialize Workflow (24h deadline per level)
         ↓
Level 1: Department Manager
    ├─ Approval → Next Level
    ├─ Rejection → Notify & Close
    └─ Delegation → New Approver
         ↓
Level 2: HR Manager
    ├─ Approval → Check Finance Impact
    ├─ Rejection → Notify & Close
    └─ Delegation → New Approver
         ↓
[Optional] Level 3: Finance Manager
    ├─ Calculate Leave Cost
    └─ Final Approval/Rejection
         ↓
Update Leave Balance & Integrate with Payroll
         ↓
Send Notifications (All Parties)

SERVICES INVOLVED:
├─ leave-approval-workflow.ts
├─ leave-payroll-calculator.ts
├─ attendance-leave-integration.ts
└─ notification-service.ts


WORKFLOW #2: PAYROLL PROCESSING (Complex Calculation)
────────────────────────────────────────────────────
Step 1: Period Setup (Lock data, prepare roster)
Step 2: Calculate Payroll (For each employee)
    ├─ Collect compensation & attendance data
    ├─ Calculate gross earnings
    │  ├─ Base salary + allowances
    │  ├─ Overtime (1.5x, 2.0x rates)
    │  ├─ Night shift allowance
    │  ├─ Bonuses
    │  └─ Gross Total
    │
    ├─ Calculate deductions
    │  ├─ Social security (10%)
    │  ├─ Health insurance (5%)
    │  ├─ Income tax (Iraq brackets)
    │  ├─ Loan installments
    │  ├─ Advance repayments
    │  └─ Absence penalties
    │
    └─ NET SALARY = Gross - Deductions

Step 3: Approval Workflow
    ├─ Department Manager Review
    └─ Finance Manager Final Approval

Step 4: Bank File Generation
    ├─ Create payment file
    ├─ Generate payslips
    └─ Create GL entries

Step 5: Payment Processing
    ├─ Submit to bank
    ├─ Bank processing (overnight)
    └─ Confirmation

Step 6: Post-Processing
    ├─ Archive period
    ├─ Send notifications
    └─ Generate reports

SERVICES INVOLVED:
├─ payroll-calculation-engine.ts (Main)
├─ iraq-tax-calculator.ts
├─ leave-payroll-calculator.ts
├─ attendance-leave-integration.ts
├─ bank-file-generator.ts
└─ notification-service.ts


WORKFLOW #3: PATIENT BILLING
──────────────────────────
Service Rendered (Doctor visit, imaging, etc.)
         ↓
Check Insurance Eligibility & Coverage
         ↓
Generate Invoice
    ├─ Service charges
    ├─ Apply insurance deduction
    └─ Calculate patient responsibility
         ↓
Payment Collection
    ├─ Insurance claim submission
    ├─ Patient payment
    └─ Update balance
         ↓
GL Posting & Reporting

BRIDGES:
├─ patient-bridge-service.ts
└─ Insurance integration


WORKFLOW #4: RECRUITMENT (Hiring Process)
─────────────────────────
Create Job Vacancy
         ↓
Publish & Recruit
         ↓
Receive Applications (All candidates auto-screened)
         ↓
Shortlist (Top candidates)
         ↓
Interview Rounds
    ├─ Round 1: HR Screening (30 min)

    └─ Round 3: Management (45 min)
         ↓
Decision Engine (Automated Scoring)
    ├─ Qualifications: 0-10
    ├─ Interview: 0-10
    ├─ Experience: 0-10
    ├─ References: 0-10
    └─ Cultural Fit: 0-10
         ↓
Make Offer
         ↓
Background Check
         ↓
Onboarding & Employee Activation

📈 CALCULATION EXAMPLES

PAYROLL CALCULATION:
────────────────
Base Components:
├─ Basic Salary:         IQD 2,000,000
├─ Housing Allowance:    IQD 400,000
├─ Transport Allowance:  IQD 200,000
├─ Meal Allowance:       IQD 100,000
= SUBTOTAL:             IQD 2,700,000

Variable Earnings:
├─ Overtime (Regular):   15 hrs × 1.5x = IQD 90,000
├─ Overtime (Weekend):   8 hrs × 2.0x = IQD 96,000
├─ Night Shift:          5 shifts = IQD 1,500,000
├─ Weekend Pay:          4 days = IQD 200,000
├─ Holiday Pay:          1 day = IQD 80,000
├─ Bonuses:             IQD 300,000
= GROSS SALARY:         IQD 4,966,000

Deductions:
├─ Social Security (10%):  IQD 496,600
├─ Health Insurance (5%):  IQD 248,300
├─ Income Tax (Iraq):      IQD 150,000
├─ Loans:                 IQD 100,000
├─ Advances:              IQD 50,000
├─ Absence Penalties:     IQD 266,000
= TOTAL DEDUCTIONS:      IQD 1,310,900

NET SALARY: IQD 3,655,100


LEAVE CALCULATION:
──────────────
Leave Days: 5 days
Daily Rate: IQD 67,200 (Gross / 30 days)
Leave Deduction: 5 × IQD 67,200 = IQD 336,000
(Applied to Payroll)


TAX CALCULATION (IRAQ):
─────────────────
Gross Salary: IQD 4,966,000
Taxable Income: IQD 4,966,000

Tax Brackets:
├─ First IQD 5,000,000 @ 3%:     IQD 148,980
├─ Remainder @ 5%:               IQD 0 (under bracket)
= TOTAL TAX:                      IQD 148,980
